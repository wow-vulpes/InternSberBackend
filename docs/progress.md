# Состояние реализации и проверки

Дата проверки: 30 октября 2026. Проверены доменные правила, схема хранения PostgreSQL, выполнение прогонов и демонстрационные данные.

## Реализовано

- Spring Boot на Java 21, Maven Wrapper, проверки версии Java и форматирования.
- Четыре доменных правила ККД, валидация входа и неизменяемый результат в стабильном порядке.
- PostgreSQL 17.11: девять таблиц, составные связи снимков, справочник правил, защита истории, проверка циклов, функция потомков и VIEW статистики.
- Liquibase 4.31.1: четыре SQL-миграции с обратными скриптами, baseline-тег, единая служебная история в public для Spring, Maven и тестов.
- Java-сценарий прогонов: согласованный снимок, расчёт реальными правилами, сохранение проблем, выбор предыдущего успешного прогона.
- Savepoint для отката частичных результатов и сохранения FAILED; сериализация обычных прогонов и демо общей блокировкой.
- Демо: 24 цели, 3 подразделения и 2 прогона, атомарная инициализация, повторный/параллельный старт без дублей.
- Отдельные команды запуска прогонов и демо; по умолчанию выключены.
- Compose для PostgreSQL, конфигурация через окружение.

## Результаты проверок

| Проверка | Результат |
| --- | --- |
| Полный Maven verify, JDK 21, Maven 3.9.11 | Успешно, исполняемый JAR создан |
| Доменные тесты | 99 сценариев, без ошибок и пропусков |
| DatabaseSchemaTest | 17 сценариев: ключи/связи, numeric, статусы, сравнение, циклы, потомки, защита истории, VIEW |
| DatabaseConcurrencyTest | 1 сценарий: запись блокирует завершение; поздняя запись отклоняется |
| MigrationLifecycleTest | 1 сценарий: повторяемость наката, откат заполненной истории, полное восстановление структуры |
| RunServiceIntegrationTest | 17 сценариев: состав демо, реальные проблемы, история, ошибки и откат, конкуренция, согласованность источника, точность numeric |
| StartupCommandsTest | 7 сценариев: обычный старт, режимы, даты/UTC, ошибки, демо без лишнего прогона |
| KkdApplicationTest | 1 сценарий: Spring-контекст с временной БД, автоматический накат, четыре правила |
| Отдельные Maven-процессы | update → rollback к kkd-baseline → update → update успешно |
| Запуск JAR после Maven-миграций | Успешно, 5 записей истории сохранены; GET /api/runs возвращает ожидаемый 404 |

Итого: 143 автоматических сценария без ошибок и пропусков. MigrationLifecycleTest и RunServiceIntegrationTest используют пользователя kkd, чтобы проверить работу при совпадении имени пользователя и бизнес-схемы PostgreSQL.

После накатов отдельно проверены 9 бизнес-таблиц, 4 правила и 5 записей истории Liquibase. После отката бизнес-схема отсутствует, служебные таблицы остаются пустыми. Интеграционный тест сравнивает таблицы, колонки, ограничения, индексы, функции, триггеры и VIEW до и после отката.

Окружение: Linux, PostgreSQL 17.11, Testcontainers 1.21.4, Docker 29.9.1. Проверки использовали отдельные временные БД; приложение остановлено, временные контейнеры и том проверки удалены.

Демонабор содержит 3 новые, 5 сохраняющихся и 5 исправленных проблем во втором прогоне; это проверка данных, а не готовый API сравнения.
