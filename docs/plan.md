# План реализации

Объём: Java backend, PostgreSQL, REST API, миграции, демонстрационные данные, тесты и документация. Frontend исключён из согласованного объёма.

| Шаг | Результат | Проверки | Статус |
| --- | --- | --- | --- |
| 1 | Каркас Spring Boot, Maven Wrapper, конфигурация | Компиляция, контекст, сборка | Завершён; 85b503b |
| 2 | Четыре правила ККД | Правила, границы, неактивные цели | Завершён; fc3fb7d |
| 3 | БД, снимки, иерархия, миграции | Целостность, конкуренция, накат/откат/повторный накат | Завершён |
| 4 | Выполнение прогонов и демоданные | 24 цели, 3 подразделения, 2 прогона, повторный старт | Реализован и проверен |
| 5 | Метрики и сравнение | Формулы, потомки, первый прогон, категории дельты | Реализован и проверен |
| 6 | REST API | Контракты, фильтры, пагинация, 404/422 | Не начат |
| 7 | Полный Docker Compose и CI | Запуск одной командой, автоматические проверки | Не начат |
| 8 | Итоговая проверка и материалы сдачи | Чистый запуск по README, соответствие спецификации | Не начат |

Схема хранения, Java-сценарий прогонов, демоданные и прикладной расчёт метрик/дельты реализованы. Compose содержит только PostgreSQL. Наличие требований к будущим функциям не означает их готовность.

Требования и критерии приёмки: [requirements.md](../specs/requirements.md). Архитектура и контракты: [design.md](../specs/design.md). Результаты выполненных проверок: [progress.md](progress.md).
