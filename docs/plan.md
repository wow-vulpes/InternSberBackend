# План реализации

Объём: Java backend, PostgreSQL, REST API, миграции, демонстрационные данные, тесты и документация. Frontend исключён из согласованного объёма.

| Шаг | Результат | Проверки | Статус |
| --- | --- | --- | --- |
| 1 | Каркас Spring Boot, Maven Wrapper, конфигурация | Компиляция, контекст, сборка | Завершён; 85b503b |
| 2 | Четыре правила ККД | Правила, границы, неактивные цели | Завершён; fc3fb7d |
| 3 | БД, снимки, иерархия, миграции | Целостность, конкуренция, накат/откат/повторный накат | Завершён |
| 4 | Выполнение прогонов и демоданные | 24 цели, 3 подразделения, 2 прогона, повторный старт | Реализован и проверен |
| 5 | Метрики и сравнение | Формулы, потомки, первый прогон, категории дельты | Реализован и проверен |
| 6 | REST API | Контракты, фильтры, пагинация, 404/422 | Реализован и проверен |
| 7 | Полный Docker Compose и CI | Запуск одной командой, автоматические проверки | Реализован; локальные проверки и GitHub Actions пройдены для 5afaace |
| 8 | Итоговая проверка и материалы сдачи | Чистый запуск по README, соответствие спецификации | Завершён локально; внешние ограничения перечислены в материалах сдачи |

Схема хранения, Java-сценарий прогонов, демоданные и прикладной расчёт метрик/дельты и REST API реализованы. Compose запускает приложение и PostgreSQL с миграциями и демо; CI workflow добавлен. Все восемь этапов согласованного backend-объёма выполнены. GitHub Actions пройден для 5afaace; Windows и корпоративная среда отдельно не проверены.
